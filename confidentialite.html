Politique de confidentialité

Cette politique concerne l’automatisation personnelle Cours PDF, administrée par le titulaire du compte GitHub guinota.

Accès aux données Google

L’application demande l’autorisation https://www.googleapis.com/auth/drive. Celle-ci donne techniquement accès en lecture et en écriture aux fichiers Google Drive autorisés par ce niveau d’accès ; elle n’est pas limitée par Google au seul dossier de destination.

Le programme utilise rclone pour examiner les noms, identifiants, dates et autres métadonnées nécessaires à la comparaison des fichiers et pour créer ou actualiser les fichiers produits dans le dossier de destination configuré. Son usage prévu est la copie des PDF pédagogiques et des rapports de compilation depuis GitHub vers ce dossier.

Finalité et destinataires

Les données servent uniquement à exécuter ce transfert personnel. Les fichiers concernés sont traités par les serveurs GitHub Actions et Google Drive. Le programme ne vend pas ces données, ne les utilise pas à des fins publicitaires ni pour entraîner un modèle d’intelligence artificielle, et ne modifie pas les autorisations de partage Drive.

Identifiants et conservation

Le propriétaire enregistre les identifiants OAuth et les jetons dans les secrets du dépôt GitHub privé. À chaque transfert, une configuration temporaire est créée sur le serveur d’exécution et supprimée à la fin de l’étape. Les secrets restent enregistrés dans GitHub jusqu’à leur suppression par le propriétaire.

Les derniers PDF et leur état de compilation sont conservés dans une branche du dépôt privé et dans le dossier Drive. La configuration actuelle conserve les archives de compilation GitHub pendant cinq jours et les journaux techniques pendant trois jours. Les fichiers et l’historique des dépôts restent conservés tant que leur propriétaire ne les supprime pas.

Contrôle et révocation

Le propriétaire peut désactiver le workflow, supprimer ses secrets GitHub et révoquer l’autorisation depuis les connexions à son compte Google. Révoquer l’accès ne supprime pas les fichiers déjà copiés ; leur suppression se fait dans Drive et, si nécessaire, dans GitHub.

Ce site d’information

Ce site statique ne comporte ni formulaire, ni outil de mesure d’audience ajouté par l’application. GitHub Pages journalise notamment l’adresse IP des visiteurs pour ses besoins de sécurité, selon la politique de confidentialité de GitHub.

Contact

Les questions peuvent être adressées via les demandes du dépôt d’information. Ce canal est public : n’y joignez pas de données confidentielles.
