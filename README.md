# Cours PDF — informations publiques

Pages statiques présentant l’automatisation personnelle Cours PDF, sa confidentialité et ses conditions d’utilisation.

Ce dépôt contient uniquement ces pages d’information. Les sources pédagogiques, PDF et identifiants OAuth ne sont pas présents dans ce dépôt.

## Publication GitHub Pages

Dans **Settings → Pages**, choisir **Deploy from a branch**, puis **main** et **/ (root)**, et enregistrer.

Après publication, vérifier les adresses affichées par GitHub Pages avant de les renseigner dans Google Auth Platform :

- accueil : `https://guinota.github.io/Cours-pdf-info/`
- confidentialité : `https://guinota.github.io/Cours-pdf-info/confidentialite.html`
- utilisation : `https://guinota.github.io/Cours-pdf-info/conditions.html`
- domaine autorisé Google : `guinota.github.io`
