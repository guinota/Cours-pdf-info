Cours PDF

Cours PDF est une automatisation personnelle destinée à compiler des documents pédagogiques LaTeX dans GitHub Actions et à copier les PDF et leurs rapports de compilation vers un dossier Google Drive choisi par leur propriétaire.

Fonctionnement

Les sources et les PDF sont conservés dans un dépôt GitHub privé. Après compilation, rclone copie les fichiers produits vers le dossier Drive configuré. Le transfert actualise les fichiers correspondants sans supprimer les autres fichiers du dossier.

L’autorisation Google est accordée par le propriétaire du compte. L’application sert à son usage personnel ; elle ne propose pas d’inscription au public.

Données et autorisation

L’autorisation Drive demandée permet techniquement d’accéder aux fichiers du compte. Le programme est configuré pour travailler dans le dossier de destination sélectionné ; cette configuration ne réduit pas la portée de l’autorisation Google.

Les traitements, la conservation et la révocation de l’accès sont détaillés dans la politique de confidentialité. Consultez également les conditions d’utilisation.

Contact

Pour une question concernant cette automatisation, utilisez les demandes du dépôt d’information. N’y publiez aucun identifiant, jeton d’accès ou document privé.
